# Dennis Schülting

I'm doing an MSc double degree at NHH (Bergen) and the University of Mannheim, and I interned at nFront Ventures in summer 2026. I care about venture capital and the data work behind it: sourcing, screening, and testing what actually predicts outcomes. I build the tools for that myself, from asset-pricing pipelines in Python and R to automated deal-sourcing workflows.

**Focus:** venture capital · data analytics · automation

**Tech stack:** Python (pandas, NumPy, scikit-learn, matplotlib) · R · TypeScript/React · n8n · Claude API · Git

### Selected projects

- **[The Disruption Score](https://github.com/schuelting15/vc-disruption-score)**: links 10-K business descriptions to venture-backed start-ups by text similarity. It tests, with a pre-registered design that avoids look-ahead bias, whether VC funding into a firm's product space predicts its stock returns (Python, R).
- **[Pulse](https://github.com/schuelting15/pulse-founder-checkin)**: a concept prototype of a quarterly founder check-in for a VC platform team. It handles validated impact KPIs with an audit trail and routes founder requests to the best-matching helper (TypeScript/React, 108 unit tests).
- **[A/B testing and multi-armed bandits](https://github.com/schuelting15/ab-testing-bandits)**: cleans and analyses about 60,000 app sessions from a three-arm recommendation experiment, then simulates ε-greedy, UCB1 and Thompson Sampling. Thompson Sampling cuts regret against a fixed split by about 97% (R, synthetic data).
